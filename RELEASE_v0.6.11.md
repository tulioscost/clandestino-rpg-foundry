# CLANDESTINO v0.6.11 — Dado exclusivo e módulos necessários

Atualização do sistema CLANDESTINO — Horror Espacial para Foundry VTT 14.368.

## Novidades
- **D6 CLANDESTINO — Neon:** conjunto visual de seis faces para o Dice So Nice, com o emblema triangular do sistema na face **6**. O preset aparece nas configurações do Dice So Nice quando o módulo está ativo.
- **Módulos necessários:** Dice Tray (`dice-calculator`), Dice So Nice (`dice-so-nice`), Chat Commands (`_chatcommands`) e Global Progress Clocks (`global-progress-clocks`).
- **Ficha reorganizada:** Talentos de Trilha em três colunas e Condições em quatro colunas, com quebra responsiva em janelas menores.

## Instalação
1. Faça backup do Mundo.
2. Publique a Release `v0.6.11` com os anexos `system.json` e `clandestino-rpg-foundry.zip`.
3. Atualize o sistema pelo manifesto: https://github.com/tulioscost/clandestino-rpg-foundry/releases/latest/download/system.json
4. Instale e ative os quatro módulos necessários.
5. No Dice So Nice, selecione o preset **CLANDESTINO — Neon**.

**Atenção:** o visual personalizado afeta apenas a apresentação; resultados de rolagens continuam sendo calculados normalmente pelo sistema. A compatibilidade e o carregamento em jogo precisam de teste no Foundry 14.368.
