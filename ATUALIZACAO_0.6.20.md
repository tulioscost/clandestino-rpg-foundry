# CLANDESTINO v0.6.20 — Dado de BPM Crítico

- Novo visual d6 **CLANDESTINO — BPM Crítico** no Dice So Nice.
- Faces 1–5 preservadas e face 6 substituída por coração com eletrocardiograma.
- Quando o personagem está com **BPM > 120**, o sistema escolhe automaticamente esse visual nas rolagens da ficha (Dice So Nice ativo).
- Com BPM ≤ 120, o sistema **não força** nenhuma aparência: mantém a escolhida pelo jogador.
- **Sem alterações mecânicas**: pool, sucessos, dificuldade e resultados preservados.
- Fallback automático sem Dice So Nice.

Verificação estrutural de JavaScript e arquivos realizada; teste em Foundry V14.368 recomendado.
