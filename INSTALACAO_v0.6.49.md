# CLANDESTINO — v0.6.49 | Instalação no Foundry

1. Faça backup do Mundo.
2. No GitHub publique os arquivos da pasta `Repositorio` na raiz do repositório de sistema.
3. Crie a tag `v0.6.49` e anexe `Release/system.json` e `Release/clandestino-rpg-foundry.zip` na Release.
4. Atualize o sistema no gerenciador do Foundry V14 e reinicie o Mundo.
5. Abra o painel RÁDIO PORTÁTIL acima da Data Terrestre; selecione um usuário conectado, digite e transmita.
6. Nos compêndios importe um Item da pasta 06A para a ficha; clique **Usar 1** para aplicar o teste de Resistência.
7. Confira a tabela **07 — Abuso de Substâncias (3d6)**. Para reiniciar os contadores de cena do ator selecionado, um usuário com permissão pode usar `game.clandestinoSubstances.resetScene(actor)`.

**Avisos:** detalhes de gravidade, limite e dificuldade são playtest; mensagem privada usa mecanismo Whisper padrão do Foundry, não criptografia ponta a ponta. Confirmar testes com dois clientes e Narrador antes de jogar.
